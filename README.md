CANCHALIBRE:
Plataforma web para organizar partidos de fútbol, encontrar jugadores y completar equipos disponibles.

Descripción:
CanchaLibre nace como una iniciativa para facilitar la organización de encuentros deportivos, permitiendo que los jugadores creen partidos, encuentren encuentros disponibles y completen equipos.

Objetivo:
Conectar jugadores de fútbol y facilitar la organización de partidos en Cartagena, Colombia.

Tecnologías:

- Java 21
- Spring Boot 3
- React
- PostgreSQL
- Docker
- Git y GitHub

Modalidades:

- Fútbol 5
- Fútbol 7
- Fútbol 11
